IMAGE - Images disque amorcables de MSDOS-0
===========================================

DOS144A.IMG   Disquette 1,44 Mo (FAT12) AMORCABLE : IO.SYS, MSDOS.SYS,
              COMMAND.COM (dossier SYSTEM) et une partie des commandes.
              Secteur de boot : celui de MS-DOS 6.22 (ecrit par SYS.PAS) ;
              IO.SYS et MSDOS.SYS sont les deux premieres entrees de la
              racine et sont contigus, comme sur une vraie disquette systeme.
DOS144B.IMG   Disquette 1,44 Mo de donnees : le reste des commandes.
              (Les 62 commandes compilees avec TPC occupent 1,8 Mo : elles ne
              tiennent pas sur une seule disquette, MAKEDISK les repartit.)
DOSCD.ISO     CD-ROM ISO 9660 amorcable (El Torito, emulation de disquette
              1,44 Mo : le boot se fait sur DOS144A.IMG, qui est aussi dans
              l'ISO) contenant tous les fichiers du systeme et des commandes
              a la racine.

SYSTEM\       Fichiers systeme utilises pour fabriquer les images.
MAKEIMG.BAT   Reconstruit les images avec TOOLS\MAKEDISK.EXE.

Comment les images sont fabriquees
----------------------------------
TOOLS\MAKEDISK.PAS orchestre les commandes du depot :

  FORMAT.PAS     cree et formate le fichier d'image  (FORMAT fich 1440 /CREATE)
  SYS.PAS        copie IO.SYS, MSDOS.SYS, COMMAND.COM, ecrit le secteur de
                 boot MS-DOS (et, pour un disque dur, le chargeur MBR et la
                 partition active)                    (SYS /IMG:fich [/ACTIVE])
  DISKPC.PAS     copie les commandes dans l'image      (TOOLS\DISKPC.PAS)
  UNDISKPC.PAS   extrait le contenu d'une image        (TOOLS\UNDISKPC.PAS)

  MAKEDISK image.img [/FLOPPY[:taille]] [/HD[:Mo]] [/FS:FAT12|FAT16]
                     [/KERNEL:dossier] [/CMDS:dossier] [/MASK:masque,...]
                     [/ADD:fichier] [/TOOLS:dossier] [/ISO:fichier.iso]
                     [/LABEL:nom] [/EXTRACT:dossier] [/NOBUILD] [/V]

- Si les fichiers ne tiennent pas sur une disquette, MAKEDISK en cree
  plusieurs : DOS144A.IMG (amorcable), DOS144B.IMG, DOS144C.IMG... (la lettre
  finale du nom est incrementee ; premier ajustement par taille de grappe et
  nombre d'entrees de la racine).
- /ISO ecrit lui-meme le CD-ROM (ISO 9660 niveau 1 + El Torito).
- /HD cree une image de disque dur (MBR + partition FAT16 active).

Exemples (dossier IMAGE, commandes compilees dans CMDS) :
  ..\TOOLS\MAKEDISK DOS144A.IMG /KERNEL:SYSTEM /CMDS:CMDS /ISO:DOSCD.ISO
  ..\TOOLS\MAKEDISK DISQUE.IMG /HD:64 /KERNEL:SYSTEM /CMDS:CMDS
  ..\TOOLS\MAKEDISK DOS144A.IMG /NOBUILD /EXTRACT:CONTENU

Compilation des outils (TPC ou Turbo Pascal 7) : FORMAT.PAS, SYS.PAS,
TOOLS\MAKEDISK.PAS, TOOLS\DISKPC.PAS et TOOLS\UNDISKPC.PAS ; MAKEDISK lance
les autres outils (dossier de MAKEDISK, /TOOLS:, courant ou PATH).
Les images livrees utilisent les commandes compilees avec TPC (dossier
CMDS : tous les .PAS de la racine) et le noyau KERNEL\MAKER.PAS.

Demarrage
---------
- Sur PC / VM : monter DOS144A.IMG comme disquette A: (ou booter sur
  DOSCD.ISO). Le noyau detecte le lecteur d'amorcage (DL du BIOS) : A: pour
  une disquette, C: pour un disque dur ; CONFIG.SYS, COMMAND.COM et COMSPEC
  sont cherches sur ce lecteur.
- Banc d'essai headless de l'emulateur DEVENV (dev-cools\DEVENV.PAS) :
    devenv /KERNELTEST,dossier /KTBOOTIMG:IMAGE\DOS144A.IMG /KTSCRIPT:t.txt
  (image <= 2,88 Mo : disquette 00h ; sinon disque dur 80h). Le secteur de
  boot est execute en 0000:7C00 : VBR -> IO.SYS -> COMMAND.COM (invite A:\>).
  Pour tester l'ISO : devenv /KERNELTEST,dossier /KTBOOTIMG:IMAGE\DOSCD.ISO ...
  ou, dans l'IDE : devenv /CDROM:IMAGE\DOSCD.ISO puis la commande BOOT du
  terminal (emulation disquette El Torito : l'image de boot est montee sur A:).
